# Employee Management System – Java MVC

Projet académique

---

## 📌 Description
Application Java basée sur l’architecture **MVC** permettant la gestion des employés :
- authentification
- gestion des employés
- gestion des congés

---

## 🧱 Architecture
- Controller : logique de contrôle
- Model : entités métier
- DAO : accès aux données
- View : interface utilisateur
- Utilities : classes utilitaires

---

## 🛠 Technologies
- Java
- JDBC
- Architecture MVC
- Programmation Orientée Objet

---

## 🎯 Objectif pédagogique
Appliquer les bonnes pratiques de développement logiciel  
et la structuration d’une application Java professionnelle.
